# Simple CNN

MNIST を対象としたシンプルな CNN の実装です．
畳み込み層と全結合層を同時に学習する最小構成にしています．

## Tested environment

+ OS: Ubuntu 22.04 LTS
+ Python: 3.10.12
+ NumPy: 2.2.6
+ TensorFlow: 2.20.0

## Install & Run

```bash
git clone https://github.com/nacky823/simple_cnn.git
cd simple_cnn
```
```bash
python3 simple_cnn.py
```
